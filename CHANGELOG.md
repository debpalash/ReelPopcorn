# Changelog

## 0.1.0 — 2026-11-14

First public alpha of ReelPopcorn for macOS.

- TMDB catalog, title/IMDb lookup and local watchlists.
- YouTube scene discovery using yt-dlp and Invidious, with playlist expansion.
- Subtitle-based timeline proposals, review, overlap trimming and visible gaps.
- Separate episode timelines and full-runtime timing-source import.
- Compact theater, immersive mode and native playback controls.
- Video.js adapters for imported YouTube, Vimeo, Twitch, TikTok and Spotify links.

Complete runtime coverage and silent-scene matching are not guaranteed.
iOS, Android, Developer ID signing and notarization are not included in this alpha.
